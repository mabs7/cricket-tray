Engineered for Reliability

Why PAK Cricket?

Designed from the ground up to stay out of your way while never missing a ball during Pakistan internationals or the PSL.

🇵🇰

Pakistan & PSL Only

Automatically filters for Pakistan international fixtures (Men, Women, U19, Shaheens/A) and all Pakistan Super League franchises — zero clutter from unrelated leagues.

📌

Sticky Bar Without Focus Theft

On Windows, a dedicated Win32 visibility watchdog restores the floating bar and keeps it on top using SW_SHOWNOACTIVATE so it never interrupts your typing or coding.

🛡️

Stale-Safe Atomic Snapshots

Network hiccup during a tense chase? Failed refreshes or missing live scores never wipe your screen. The widget retains the last verified score and clearly shows its age.

🔍

Layered Cricbuzz Parser

Decodes embedded JSON and Next.js flight streams first, falling back to match-ID-scoped HTML and JSON-LD metadata. Normalizes cricket ball notation (19.6 → 20) and validates wickets.

🔄

Verified Portable Updater

Checks GitHub Releases every 6 hours. On Windows, clicking Update streams the ZIP, verifies its SHA-256 digest, backs up the old .exe, and rolls back automatically if startup fails.

🕵️

Zero Telemetry & API-Key-Free

No sign-ups, no paid cricket API keys, no background services, and zero user analytics or installation tracking. Preferences live locally on your machine.

Under the Hood

How the Score Engine Works

01 / CONCURRENT FETCH

Live, Recent & Upcoming

Polls every 45s when a match is live, 5m when scheduled today, and 30m when idle.

02 / PURE PARSER

Embedded + Scoped HTML

Extracts structured match records without ever executing page scripts, validating runs, wickets, and overs.

03 / SMART PRIORITIZATION

Live → Today → Recent

Deduplicates by match ID and orders live matches first, upcoming fixtures next, and up to 3 recent results.

04 / THREAD-SAFE UI

Non-Blocking Desktop UI

Delivers deep-copied atomic snapshots to Tkinter/pystray on Windows or rumps on macOS.
